# How to Find PostScript Name in Font Book

Since you installed the font, follow these steps:

## Method 1: Find Font in Font Book

1. **Open Font Book** (I just opened it for you)

2. **In Font Book's search bar** (top right), type: `Oscine`

3. **You should see font families** - look for:
   - "Oscine Trial" or "Oscine" family
   - Click on it to expand

4. **Look for these specific fonts:**
   - "Oscine Trial Regular" (this is Oscine_Trial_Rg.ttf)
   - "Oscine Trial ExtraBold" (this is Oscine_Trial_XBd.ttf)

5. **Click on "Oscine Trial Regular"** (or just "Regular" under Oscine Trial)

6. **Press `Cmd + I`** (or click the "i" button in the toolbar)

7. **In the Info panel, look for:**
   - **"PostScript name:"** - This is what we need!
   - It might be something like:
     - `OscineTrial-Rg`
     - `OscineTrialRg`
     - `Oscine-Trial-Rg`
     - `OscineTrial-Regular`

8. **Copy the EXACT PostScript name** (case-sensitive!)

9. **Repeat steps 5-8 for "Oscine Trial ExtraBold"**

---

## Method 2: If Font Book Doesn't Show It

If you can't find it in Font Book:

1. In Font Book, go to **View → Collections → All Fonts**
2. Look for any font starting with "Oscine"
3. Or try **File → Add Fonts...** and browse to the font file again
4. Select the font file and click "Open"
5. Then select it and press `Cmd + I` to see the info
