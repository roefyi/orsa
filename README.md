# Orsa

Orsa is a no-fluff espresso journal that eliminates tedious data entry by auto-populating brew parameters. Users can log shots quickly, track their dialing-in process, and share beautiful brew cards with friends.

## Features

- **Auto-populated brew parameters** - No tedious data entry required
- **Quick shot logging** - Log your espresso shots in seconds
- **Dialing-in tracking** - Track your process as you perfect your shots
- **Beautiful brew cards** - Share your creations with friends

## Requirements

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+

## Setup

1. Clone the repository
   ```bash
   git clone https://github.com/roefyi/orsa.git
   ```
2. Open `orsa.xcodeproj` in Xcode
3. Build and run the project
