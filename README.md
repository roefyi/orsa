# Orsa

A SwiftUI iOS application.

## Requirements

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+

## Setup

1. Clone the repository
2. Open `orsa.xcodeproj` in Xcode
3. Build and run the project

## Description

Orsa is a SwiftUI-based iOS application featuring a clean, modern interface.
